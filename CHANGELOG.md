# Changelog

All notable changes to this project are documented here.

This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-08-22

### Initial release

- Manual on/off toggle for blocking
- Site list management, add and remove domains from the popup
- Quick-add current site with one click, grabs the active tab's domain
- Message categories (Social, Shopping, News, Video, Other), each with tailored suggestions on the block page
- Scheduled blocking, set a recurring day/time window where blocking activates automatically
- Reason gate: turning off manual blocking outside your scheduled hours requires writing an actual reason
- Streak tracking: current streak, best streak, and total times resisted, shown in the popup and on the block page
- Custom block page with a rotating list of positive suggestions (tidy up, exercise, meditate, pray, etc.)
- MIT licensed, authored by Lady Alana ([@ladyalana808](https://github.com/ladyalana808))
